為什麼是一個檔案

單檔 HTML，沒有後端

整個工具就是一個檔案。下載到隨身碟、丟進內網、寄給同事都能跑，不需要安裝任何東西，也不會有哪天服務關掉的問題。

金鑰只留在你的瀏覽器

API 金鑰存在你自己的 localStorage，請求直接送到模型供應商。沒有中介伺服器，因為這個專案根本沒有伺服器。

9 家語言模型任選

Anthropic、OpenAI、Gemini、DeepSeek、Kimi、GLM、MiniMax、Groq，加上跑在自己電腦上的 Ollama。想零成本起步就用 Groq 或 Ollama。

每一段都能編輯

模型的判斷不會是最終答案。任何一段的結果都能當場改，改完的版本會被後面的步驟沿用，而不是重跑一次碰運氣。

中英雙語，介面與產出分開

介面語言和模型的產出語言是兩個獨立的開關。可以介面看英文、產出繁中，或者反過來。

不編造數字

沒有證據的內容會被標成推論並降低信心值。具體數字、價格、客戶名稱與獎項一律不編。

授權

原始碼公開，但不是 open source

正確的說法是 source available。程式碼可以自由閱讀與修改，只有一項限制：不能把這個軟體本身當商品賣。

可以
  • 自己用、公司內部用
  • 修改它、發布你的修改版
  • 拿去上收費課程與企業內訓
  • 用在你提供給客戶的專業服務裡
不可以
  • 把它當產品販售，包含改名換皮的版本
  • 架成 SaaS 或線上服務對外收費
  • 做出功能實質相同的競品
  • 移除原始碼裡的著作權標示
判斷原則：教學可以收費，軟體本身不可以。另外每個版本在釋出滿兩年後會自動轉為 MIT 授權，屆時所有限制解除。需要落在禁止範圍內的使用方式，歡迎來信談商用授權。
